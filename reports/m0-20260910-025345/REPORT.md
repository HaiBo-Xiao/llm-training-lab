# M0 最小训练检查

阶段：M0 / A0，部分完成。

研究问题：目标 GPU 能否完成参数更新，并从保存的训练状态恢复出一致的下一步？

配置：
  - 单个参数 w，初值 0，目标值 3。
    - 损失：(w - 3)^2。
    - SGD，学习率 0.1，动量 0.9。
      - 无随机初始化、无随机采样，因此本次随机种子不适用。
      - 固定执行两步连续更新，以及一次恢复后的更新。

结果：
  - 第一步：更新前 loss=9，更新后 w=0.6。
    - 第二步：连续训练与恢复训练均得到 w=1.62。
      - 数值检查通过，进程退出码为 0。

      证据：
        - check_training.py：执行代码与配置快照。
        - pyproject.toml、uv.lock、.python-version：环境定义。
        - environment.txt：环境信息。
        - command.txt、output.txt、exit_code.txt：命令与运行结果。

结论与边界：
  - 本例的 CUDA 计算、梯度、参数更新和训练状态恢复检查通过。
    - 保存恢复使用内存中的 BytesIO，未验证磁盘检查点或独立进程恢复。
      - 尚未验证最小环境重建，A0 暂不标记通过。

      下一步：使用保存的环境定义，在独立目录重建环境并重复检查。
