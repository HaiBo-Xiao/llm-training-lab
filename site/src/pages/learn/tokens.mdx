### 编码与解码

对原始文本去重、排序，得到词表 `['。', '吃', '小', '猫', '鱼']`。`stoi` 是 string-to-integer，负责字符到 ID；`itos` 负责反方向的映射。

```text
字符： 小  猫  吃  鱼  。
ID：   2   3   1   4   0

encode("小猫吃鱼。") → [2, 3, 1, 4, 0]
decode([2, 3, 1, 4, 0]) → "小猫吃鱼。"
```

编码再解码应还原出原文。本轮只处理词表内字符；下一章再引入未知字符记号。

### 输入与目标错开一格

每个输入位置的目标，是原序列中紧接着它的字符。去掉原序列最后一项得到输入 x，去掉第一项得到目标 y。

```text
完整序列： [2, 3, 1, 4, 0]  小猫吃鱼。
输入 x：   [2, 3, 1, 4]     小猫吃鱼
目标 y：   [3, 1, 4, 0]     猫吃鱼。
```

| 输入位置 | 此时允许使用的前缀 | 要预测的字符 |
| --- | --- | --- |
| 0 | 小 | 猫 |
| 1 | 小猫 | 吃 |
| 2 | 小猫吃 | 鱼 |
| 3 | 小猫吃鱼 | 。 |

这里准备好了任务。真正限制模型读取未来信息，需要后续的[因果遮罩](/learn/attention/)。
