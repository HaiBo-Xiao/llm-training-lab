## 这一步要解决什么

前向计算已经给出了各候选字符的 logits。接下来要将它们与已对齐的目标比较，为每个有效预测位置计算误差，并汇总成一个损失。

部分位置可能被 `ignore_index` 标记为忽略。计算平均损失时，要分清张量总位置数与实际参与监督的位置数。

## 本轮四项任务

| 顺序 | 任务 | 要核对的内容 |
| --- | --- | --- |
| 1 | 整理交叉熵输入 | logits 与目标的位置对应关系 |
| 2 | 计算逐位置损失 | 返回各位置的损失，处理忽略标记 |
| 3 | 构造有效 token mask | 哪些位置参与监督 |
| 4 | 求有效位置平均损失 | 使用正确的分母 |

题面、输入输出示例和自检均已在 [练习源码](/source/loss/) 中准备好。训练与学习练习由学习者填写并执行。

```bash
uv run --locked python scripts/05_inspect_loss.py
```

## 完成后记录什么

记录退出码、打印出的有效 token 数与平均损失，然后更新 [任务进度](/source/tasks/)。这一步完成后，继续组合 decoder-only 模型，接入 backward 与最小训练步。
