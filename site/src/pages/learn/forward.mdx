### Embedding 是一次查表

E 有四行、两列。每个 ID 选择对应的一整行，得到一个二维向量。

| ID | 字符 | E 中的向量 |
| --- | --- | --- |
| 0 | 。 | [0, 0] |
| 1 | 小 | [1, 0] |
| 2 | 猫 | [0, 1] |
| 3 | 鱼 | [1, 1] |

“小”的 ID 为 1，因此取出 E 的第 1 行 `[1, 0]`。本步骤尚未加入位置或上下文，同一个 ID 总会查到同一个向量。

### 向量如何变成分数

输出权重 W 有两行、四列，每一列对应一个候选字符。将向量 h 与每一列做点积，得到 logits。

```text
候选字符：  。   小   猫   鱼
W = [
  [        0,   1,   2,  -1],
  [        0,  -1,   1,   2],
]

输入“小”：h = [1, 0]
logits = h @ W = [0, 1, 2, -1]
最大分数对应 ID 2，也就是“猫”。
```

logits 是尚未归一化的分数，可以为负，总和也不要求为 1。当前使用 argmax 取最大分数的下标；这些固定权重产生的结果，不表示模型已经通过训练学会了语言。

### 保留批次与位置维度

实际练习的 B = 2、T = 3、D = 2、V = 4。前向计算始终保留前两维，在最后一维上完成查表与投影。

| 数据 | 形状 | 含义 |
| --- | --- | --- |
| x | [2, 3] | 两条样本，每条三个 ID |
| h | [2, 3, 2] | 每个位置取出二维向量 |
| logits | [2, 3, 4] | 每个位置对四个候选打分 |
| pred | [2, 3] | 每个位置选出一个预测 ID |

完整实现见 [03_inspect_forward.py](/source/forward/)，实现提交 `7131d2`，形状与数值自检通过。来源见 [任务记录](/source/tasks/)。
